# AUVIO

A lightweight, native cross-platform video and music player for Windows and Linux, built in C++ with Qt and FFmpeg.

## Status

Early development — not yet runnable.

## Planned Stack

- C++17/20
- FFmpeg (decode/demux)
- Qt (UI)
- OpenGL / Vulkan (rendering, hardware acceleration)
- CMake + vcpkg (build & dependencies)
